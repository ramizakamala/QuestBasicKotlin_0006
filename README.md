## Cara Menjalankan di Kotlin Playground

1. Buka <https://play.kotlinlang.org>
2. Salin seluruh isi salah satu file `subbab/*.kt` ke editor.
3. Klik tombol **Run** (atau tekan `Ctrl + Enter`).
4. Hasil running muncul di panel output.
5. Screenshot hasil running (full layar) lalu simpan ke folder [`screenshots/`](screenshots/).

File `screenshots/Screenshots.md` berisi daftar screenshot hasil running tiap sub bab.

## Catatan

- Setiap file bersifat mandiri (self-contained) dan punya `fun main()` sendiri,
  sehingga bisa langsung dijalankan satu per satu di Kotlin Playground.
- Kode di setiap sub bab ditulis mengikuti materi yang diberikan, ditambah contoh
  penerapan supaya perilaku tiap fitur bahasa Kotlin terlihat jelas pada output.
- Baris kode yang sengaja tidak valid (contoh error kompilasi pada materi,
  misalnya mengisi `null` ke variabel non-nullable) ditulis sebagai komentar
  agar program tetap bisa dijalankan.
